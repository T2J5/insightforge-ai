# 3–5 分钟项目演示脚本

## 0:00–0:35 问题与结果

打开首页：企业调研不是“让模型写一篇文章”，而是让结论可回到证据。展示输入企业、关注方向、快速/深度模式和游客额度，不立即深入代码。

## 0:35–1:20 实时运行

创建一次快速调研，进入运行页。说明 Web 只创建数据库 Run 并写入 BullMQ；常驻 Worker 执行 LangGraph。指出 SSE 事件有单调 ID、Redis 回放日志和 Last-Event-ID，刷新页面后 REST 快照与事件回放共同恢复状态。

## 1:20–2:00 引用与报告

若实时运行尚未完成，打开一份预置报告。点击事实块引用，展示发布方、来源 URL、日期和逐字引文。强调网页正文是不可信输入，只有保存并通过身份、归属和支持度校验的 Evidence UUID 才能发布。

## 2:00–2:40 Graph 与恢复

展示架构图和 Planner → Researcher → Evidence → Writer → Reviewer → Publisher。说明引用失败回到检索，质量失败最多回写一次；预算和条件边由程序控制。展示 checkpoint 测试：Worker 失败重试从最新节点恢复，不重复 planner 和已持久化副作用。

## 2:40–3:25 RAG、评测与观测

说明上传文件解析、800/1,200 Token 分块、pgvector + PostgreSQL 全文检索、RRF 和重排序。打开评测结果，手工解释 Recall@5 与 MRR；明确当前表格是 51 条确定性 CI 夹具，不把夹具延迟包装成生产数据。再展示 Trace 只记录节点、耗时、Token、成本和白名单错误码。

## 3:25–4:10 安全与成本

快速说明 owner 隔离、SSRF 的 DNS/重定向复检、Prompt 注入边界、Redis 原子限流、quick/deep 预算和私有报告禁止公开。打开 `/api/health` 或 CI，证明部署和发布门禁可自动验证。

## 4:10–4:40 收尾

总结项目覆盖后端工程、RAG、Agent 编排、评测观测和业务落地五类能力。主动说明限制：扫描 PDF 无 OCR；文档上传在公开创建页暂未开放；真实在线评测和生产地址必须以最新发布记录为准。
