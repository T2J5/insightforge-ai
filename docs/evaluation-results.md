## 如何理解

这些数字验证的是“评测代码、指标计算、CI 回归阈值和三种方案对比”可以稳定复现，不是对真实互联网检索质量的宣传。夹具故意让纯向量方案把第一条相关证据排在第二位，混合方案提高关键词命中，重排序方案把所有期望证据稳定提前，因此 Recall@5 和 MRR 得到可手工核算的差异。

P95 延迟也是夹具定义的确定性操作耗时，用于验证聚合口径，不代表生产网络延迟。真实供应商结果必须通过 `Online Agent Evaluation` 手工工作流运行，生成的 `online.json`/`online.md` 才可作为线上模型、延迟和成本结论。在没有实际在线产物前，README 和简历不引用真实质量提升百分比。
